# Project entrances

Figure-sized architectural studies on the existing island. These are original
navigation metaphors, not replicas or simulations of the products. Only camera
movement responds to selection. There is no idle tour.

The black index, product facts, links, status and camera gestures stay intact.
Colour and outer ink come from Colorfigures. Anatomy supplies rounded, bevelled
convex slabs with four side tones, adapted to the same orbit camera. The copied
200-line solids subset and both MIT notices travel inside the portable output.

Parts are grouped before modelling (roughly 60 architectural assemblies across
the scene, with smaller supported parts inside each assembly):

| Project | Form and parts |
| --- | --- |
| DIP | Open meeting commons: plinth, canopy, four posts, communal table, four seats, paving |
| GIMI | Rental cottage: gable, door, windows, locker bank, individual bays, canopy, returned-item crates |
| PINGME | Open court: marked floor, table, four legs, net frame, mesh, paddles, two floodlights |
| DISTOKEN | Stepped gallery: three volumes, roof lips, fitted frames, artworks, skylight, entrance steps |
| TRANSPARENT | Play courtyard: chequered floor, paired arcade cabinets, inset screens, control decks, button pairs |
| REDLINE AI | Review library: raised base, four columns, reading room, roof, red spine, document relief, steps |
| AGENTSHACK | Market: three separate kiosks, striped awnings, posts, counters, inset agent cards |
| OUTPUT | Dispatch hub: warehouse, two loading bays, dock, crates, stepped control cabin, network mast |
| MAIAT PROTOCOL | Signal tower: three stepped stages, inspection seams, framed beacon lantern, cap, mast |
| savvy | Place archive: L-shaped archive, courtyard, roof garden, planter, map table, three place markers |
| EZNest | Layout workshop: glazed-roof shed, roof bays, supported cutting table, sheet, fitted nested pieces, stock rack |

Assemblies are sorted in camera depth; facade marks are culled with their host
face. Thin details end at their host boundaries. Plate, roof and worktable
dimensions keep within the existing building plots. The map and detail portrait
use the same drawing function. No new shaders, pipes or machinery animation.

Acceptance: eleven visibly different silhouettes at island scale; fitted details
at close range; finite SVG over a full orbit and supported tilt range; unchanged
selection, entry, reduced-motion, reset and homepage behavior. Verification is
recorded in `../VERIFICATION.md`. This adapter uses the existing Colorfigures
painter rather than Anatomy's optional live-3D engine or mechanical audit.
